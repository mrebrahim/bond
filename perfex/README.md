# Module الاستوديو والباقات لـ Perfex (`dse_studio`)

المرحلة 1: رصيد الباقات، حجز الاستوديو، السكربتات والنشر، جروبات واتساب العملاء، وتنبيه العميل اللي مابيصوّرش — كله جوه Perfex.

## التركيب
1. خد الملف `dse_studio.zip` (بيتعمل بـ `bash perfex/build.sh`).
2. Perfex → **Setup → Modules → Upload** → اختار `dse_studio.zip` → **Install** → **Activate**.
3. **Setup → Staff → Roles**: ادي كل دور صلاحيات "الاستوديو والباقات":
   - الدعم الفني: يشوف + يحجز + يعمل باقات
   - السيلز: يشوف + يعمل باقات
   - المودريشن: يشوف + يحجز (علشان يسجّل النشر)
4. **الاستوديو والباقات → الإعدادات**: حط الـ API key بتاع Evolution، واتأكد من الـ instance (`010`)، وبعدين علّم "الإرسال شغال".
5. اتأكد إن **Cron Job** بتاع Perfex شغال على السيرفر (كل 5 دقايق على الأقل) — الرسايل والتنبيهات بتمشي معاه — وإن التوقيت `Africa/Cairo` (Setup → Settings → Localization).

## الشغل اليومي
- **باقة جديدة**: اعمل الفاتورة في Perfex عادي ← من صفحة العميل في الـ module اعمل الباقة واربطها بالفاتورة. أول ما الفاتورة تبقى "مدفوعة" الباقة بتتفعل لوحدها.
- **الحجز**: من صفحة العميل — المدة واللبسات بتتحسب لوحدها، ومفيش حجز فوق بعض لنفس الاستوديو أو المصور، ومفيش حجز أكتر من الرصيد. العميل بتوصله "تم الحجز" في الجروب.
- **بعد الجلسة**: "اتصورت" + العدد الفعلي ← بيتخصم. "مجاش" / إلغاء قبل الميعاد بأقل من 24 ساعة ← بيتخصم وحدة.
- **السكربت**: "احفظ وابعت للعميل" ← بيوصل الجروب.
- **النشر**: حط لينك البوست ← العميل بيوصله اللينك + لينك التقييم + الرصيد الباقي.
- **التنبيهات**: كل يوم السيستم بيدوّر على العملاء اللي عندهم رصيد ومصوّروش من 21 يوم ومفيش حجز جاي ← إشعار في Perfex + إيميل.

## رسايل الواتساب للعميل
الأوتوماتيك 3 بس: السكربت، تم الحجز / الميعاد اتغيّر، البوست نزل. الباقي بزرار (مانوال العميل الجديد). كل رسالة بتتبعت مرة واحدة بس، وفيه حد 6 رسايل أوتوماتيك في اليوم لكل جروب. السيستم مبيردش على العميل.

## الاختبارات
`php perfex/tests/run.php` — بيشغّل الـ model على SQLite وEvolution مزيّف (من غير Perfex).
